# SI 212 — course materials

Public materials for **SI 212, Fall 2026**, University of Michigan School of Information.

Students clone this repository during first-day setup. It is **pull-only**: everything here is
maintained by the instructor, and your own work belongs in your personal course repositories,
not in this one.

## What's here now

This repository is being set up. At present it holds only what the first-day bootstrap needs:

    workflows/bootstrap/config/codex-config.toml

That file is fetched during setup and installed to `~/.codex/config.toml`. It points the Codex
app at U-M's AI gateway so that your U-M GPT Toolkit key works, and sets a starting model. The
model is a starting point, not a requirement — you will change it as you learn to weigh
capability against your token budget.

Workflows, skills, guides, templates and tools will follow.
