# Lecture slides

One file per class session, named for the session it belongs to.

Open the `.html` in any browser. Each file is self-contained — the slides, the theme and
the fonts are all inside it — so it works offline, straight from your own copy of this
repository, with no server and nothing to install.

Once a deck is open: arrow keys move through it, `Esc` zooms out to see every slide at
once, and `M` opens a menu of slide titles to jump between them.
