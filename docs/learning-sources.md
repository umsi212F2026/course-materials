# Learning sources worth starting from

Places this course has found good for an orientation reading or a first explanation. Curation
reads this list before it searches. A source here is a first place to look, not a guarantee: check
that the page still says what you need, and check any prices or limits it quotes against the
vendor's own pages.

## The web stack

- **[The Odin Project](https://www.theodinproject.com/).** A free, open-source curriculum for
  full-stack web development, maintained by volunteers. Vendor-neutral, written for beginners, and
  kept up to date. Its lessons often run past what a topic needs; that is fine, as long as the
  learner is told which sections to skip. Example: its Node-path "Deployment" lesson, read up to
  its debugging section, is the orientation for cloud hosting.
- **[MDN's Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development).**
  Mozilla's beginner track for how the web works: servers, requests, HTML, CSS, JavaScript.
  Vendor-neutral and maintained. Its short explainers, such as "What is a web server?", work well
  as a read-first before a longer lesson.
